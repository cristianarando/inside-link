## 1. Product Vision & Scope

**InsideLink v2** is a self-hosted, single-owner shortlink engine, interactive project micro-landing platform (`type = 'HUB'`), customization studio, branded QR generator, and public showcase directory (`/`) deployed standalone on **`https://links.cristianarando.dev`**.

### Architectural Evolution from v1 to v2

1. **Standalone Subdomain Topology:** Deployed directly on `https://links.cristianarando.dev` instead of reverse-proxying through `cristianarando.dev`. The root path `/` serves the public directory (`/links` permanently redirects `308` to `/`), freeing short slugs such as `/cv`, `/projects`, `/uses`, and `/blog` without cross-repository rewrite rules.
2. **100% English & Dark-Only Precision UI:** Standardized across all public surfaces, server-rendered HTML views, error envelopes, source comments, and `/admin` workflows with a dark-first aesthetic (_Obsidian & Emerald_ default plus customizable dark presets).
3. **Zero External API Tokens:** Administrative access relies exclusively on **Better-Auth GitHub OAuth** locked to `ALLOWED_GITHUB_ID` (and optional `ALLOWED_GITHUB_EMAIL`). External Bearer API keys are intentionally excluded to eliminate static credential attack surfaces.
4. **Pro v2 Capabilities:** Theme & Customization Studio, Bento Mosaic public directory, Rich HUB blocks with zero-tracker Click-to-Play embeds and live GitHub repository cards, Smart Conditional Routing, Scheduled Launch Countdowns, Expired Fallback Redirects, Fullscreen Link Cloaking with `frame-ancestors` validation, Link Health Scanning, `Cmd+K` Command Palette, Bulk Operations, Dry-Run JSON Backups, and `O(1)` SQL Analytics 3.0.

## 3. Functional Requirements (`FR`)

### 3.1. Slug Validation & Collision Prevention

| ID         | Requirement                                                                                                                                                                                                                                                                                                                                                                                                                                               | Observable Acceptance Criteria                                                                                                        |
| :--------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------ |
| **FR-001** | **System Reserved Slug Blacklist:** Block creation or update of slugs matching InsideLink internal routes (`admin`, `dashboard`, `login`, `logout`, `signin`, `signout`, `api`, `auth`, `links`, `hub`, `unlock`, `qr`, `analytics`, `settings`) and technical Next.js/web paths (`_next`, `_il`, `_vercel`, `assets`, `public`, `static`, `images`, `fonts`, `og`, `favicon`, `robots`, `sitemap`, `manifest`, `404`, `500`, `error`, `health`, `ping`). | Submitting any reserved slug returns `422 SLUG_RESERVED` in both real-time check (`/api/v1/links/check-slug`) and mutation endpoints. |
| **FR-002** | **Deterministic Slug Normalization & Syntax:** Trim input, lowercase characters, collapse whitespace into single hyphens (`-`), enforce length between `3` and `100` characters matching `^[a-z0-9]+(?:[-_][a-z0-9]+)*$`, and block static file extensions (`.ico`, `.png`, `.json`, `.xml`, `.js`, `.css`, etc.).                                                                                                                                        | `"  My Tour Guide  "` normalizes to `"my-tour-guide"`; 1–2 char slugs or dotted file extensions fail Zod validation immediately.      |
| **FR-003** | **Cryptographic Auto-Generated Slugs:** Generate collision-free 6-character lowercase alphanumeric slugs (`[a-z0-9]{6}`) outside `RESERVED_SLUGS` when `slug` is omitted.                                                                                                                                                                                                                                                                                 | Omitting `slug` on link creation persists a unique 6-character slug verified against `links.slug`.                                    |

### 3.2. Smart Resolution Engine, Scheduling & Cloaking (`GET /[slug]`)

| ID         | Requirement                                                                                                                                                                                                                                                                                                         | Observable Acceptance Criteria                                                                                                                                        |
| :--------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **FR-004** | **`DIRECT` Redirect & Query Forwarding:** Resolve active `DIRECT` links using their configured HTTP status (`307`, `301`, `302`, `308`) and merge incoming query parameters when `forward_query_params = true` without altering target scheme/host.                                                                 | `GET /linkedin?ref=cv` emits `307` with `Location` preserving `?ref=cv` in `<50ms` warm edge latency.                                                                 |
| **FR-005** | **Smart Conditional Routing:** Evaluate ordered `routing_rules` against visitor `country` (ISO-3166-1 alpha-2), `Accept-Language`, `device` (`mobile`, `desktop`, `tablet`), and `os` (`iOS`, `Android`, `Windows`, `macOS`, `Linux`) using `AND` across specified dimensions and `OR` within each dimension array. | First matching rule overrides `destination_url` (for both standard redirects and post-PIN unlocks); unmatched visitors fall back to the default `destination_url`.    |
| **FR-006** | **Scheduled Launch Countdown (`starts_at`):** Hold active links whose `starts_at > now` behind a themed dark countdown page (`dd : hh : mm : ss`) that automatically reloads at zero.                                                                                                                               | Human visitors receive `200 OK` countdown HTML without incrementing `clicks_count`; public directory cards display a `"Launching soon"` badge (`isScheduled = true`). |
| **FR-007** | **Expiration & Custom Fallback Redirect (`expired_redirect_url`):** Stop serving links past `expires_at` or with `clicks_count >= max_clicks`. If `expired_redirect_url` is configured, redirect (`307`) there without counting clicks; otherwise render the themed `410 Gone` view.                                | Expired links with a fallback redirect seamlessly route to the archive/waitlist URL; unconfigured expired links return HTTP `410 Gone`.                               |
| **FR-008** | **Clean Fullscreen Link Cloaking (`is_cloaked`):** Render `DIRECT` links with `is_cloaked = true` inside a borderless `100vw × 100dvh` iframe while preserving the shortlink URL, `<title>`, favicon, and Open Graph metadata—with zero intrusive banners.                                                          | Admins can pre-verify embeddability via `POST /api/v1/links/frame-check` (`X-Frame-Options` & CSP `frame-ancestors`).                                                 |
| **FR-009** | **Social Crawler Dynamic Open Graph:** Serve lightweight `200 OK` HTML with `og:title`, `og:description`, `og:image` (`auto`, `custom`, or `minimal` dynamic PNG cards), `og:url`, and `twitter:card` to social preview bots without counting clicks.                                                               | Bot requests never consume `max_clicks`; PIN-locked links return a generic protected Open Graph card hiding destination metadata.                                     |
| **FR-010** | **PIN Shield & Signed Unlock Cookies:** Protect links with `password_hash` (`scrypt`) behind a themed PIN form rate-limited to `5` failed attempts per `60s`. Validating `POST /api/v1/slug/[slug]/unlock` sets an `HttpOnly` HMAC-SHA256 cookie (`il_unlock_<linkId>`, 15m TTL).                                   | Locked responses (`Cache-Control: private, no-store`) never leak `destination_url` or `hub_links` prior to server verification.                                       |

Automatically include public, non-PIN `HUB` URLs in `/sitemap.xml`.                                                                                                                                                                                                                                                                    | Legacy `/links` requests redirect (`308`) to `/`; pinned cards span featured Bento cells when `directoryLayout = "bento"`.                                                   |

## 4. Non-Functional Requirements (`NFR`)

| ID          | Quality Attribute             | Target Specification                                                                                                                                                                                                  |
| :---------- | :---------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **NFR-001** | **Redirect Latency**          | Warm P95 `< 50 ms` and cold P95 `< 150 ms` on `GET /[slug]`; telemetry writes execute asynchronously via Next.js `after()`.                                                                                           |
| **NFR-002** | **DOM & Scroll Scalability**  | Initial viewport batch capped at `12–24` items with `O(1)` keyset cursor pagination `(is_pinned, id)` and `IntersectionObserver` infinite scroll.                                                                     |
| **NFR-003** | **Zero-PII Privacy**          | Raw client IP addresses are never stored in `click_events`. Rate-limit keys use UTC-day rotated SHA-256 hashes truncated to 32 hex chars.                                                                             |
| **NFR-004** | **Defense-in-Depth Security** | Strict `http:`/`https:` URL validation, SSRF-safe outbound probes, escaped SSR/DOM builders (zero unsafe `innerHTML`), `scrypt` + `timingSafeEqual` PIN verification, and single-owner GitHub OAuth lockdown.         |
| **NFR-005** | **Database Safety**           | Automatic `PRAGMA foreign_keys = ON` on local SQLite `file:` connections and mandatory `--allow-remote-wipe` guard preventing accidental `db:seed` execution against remote `libsql://` / `https://` Turso databases. |
| **NFR-006** | **Strict Code Quality**       | 100% English codebase, TypeScript `strict: true` + `noUncheckedIndexedAccess: true`, ESLint 9, Prettier, and automated Vitest unit, integration, and E2E suites.                                                      |
